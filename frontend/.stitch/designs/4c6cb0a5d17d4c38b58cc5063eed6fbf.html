Hey ExamAI, can you explain the time complexity of building a heap from an unsorted array? I'm getting confused between O(n) and O(n log n).

bolt

That's a classic interview question! While it might seem like $O(n \log n)$ because you're inserting $n$ elements, the actual complexity is **$O(n)$**1.

This is because the work done at each level of the tree decreases as you move towards the root. Specifically, most nodes are at the bottom (leaves) and require zero swaps, while only the root requires the maximum number of swaps ($\log n$)2.
