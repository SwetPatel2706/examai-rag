## Item 1.1 — Delete the dead stub router `app/routes/stubs.py`

**What:** `backend/app/routes/stubs.py` is a leftover "Phase 0" placeholder. It
defines a single `GET /api/flashcards` endpoint that always returns `501
NOT_IMPLEMENTED`. The real flashcards router (`app/routes/flashcards.py`)
serves `/api/flashcard-decks` and `PATCH /api/flashcards/{id}`; the frontend
(`frontend/src/api/flashcards.js`) only calls those. Nothing in app, tests, or
frontend calls `GET /api/flashcards`.

**Steps:**
1. Delete file `backend/app/routes/stubs.py`.
2. Edit `backend/app/main.py:121` — remove `stubs` from the import:
   ```python
   from app.routes import auth, subjects, materials, stubs, chat, flashcards, quizzes, analytics, me
   ```
   →
   ```python
   from app.routes import auth, subjects, materials, chat, flashcards, quizzes, analytics, me
   ```
3. Edit `backend/app/main.py:130` — remove `app.include_router(stubs.router)`.
4. Edit `backend/tests/test_smoke.py` — delete the whole `TestStubEndpoints`
   class (lines 104–131). Also update the module docstring (lines 8–9) that
   says "All stub routes → 501": change to list only health endpoints.

**Why:** dead endpoint + dead tests + dead wiring. Keeping it misleads future
readers into thinking flashcards are unimplemented.
